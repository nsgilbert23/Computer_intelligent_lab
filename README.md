# Telco Customer Churn Analysis

**A Data Preprocessing and Exploratory Data Analysis Lab Using Python**

## 1. Project Overview

This project analyzes the Telco Customer Churn dataset to explore customer characteristics and service or payment arrangements associated with customer churn.

The lab focuses on data preprocessing and exploratory data analysis (EDA) using Python. It examines demographic characteristics, phone service, contract types, paperless billing, and payment methods to identify patterns in customer retention and churn.

## 2. Objectives

The main objectives of this lab are to:

- Load and inspect the Telco Customer Churn dataset.
- Examine the first and last records of the dataset.
- Convert the `Churn` attribute from `Yes`/`No` to `1`/`0`.
- Inspect and correct data types.
- Identify missing values and remove records containing null values.
- Explore the relationship between customer churn and selected demographic, service, and payment attributes.
- Visualize the results and interpret the findings.

## 3. Dataset Description

The dataset used in this project is **Telco Customer Churn**, obtained from Kaggle.

**Source:** [Telco Customer Churn Dataset on Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

The original dataset contains 7,043 customer records and 21 attributes. It includes information about customer demographics, subscribed services, account information, billing arrangements, and churn status.

The `Churn` attribute indicates whether a customer left the company.

- `1` — Customer churned.
- `0` — Customer did not churn.

## 6. Exploratory Data Analysis

The lab investigates the following relationships with customer churn.

### Demographic Analysis

- **Gender:** Compares churn across female and male customers.
- **SeniorCitizen:** Examines differences between senior and non-senior customers.
- **Partner:** Investigates churn among customers with and without partners.
- **Dependents:** Examines churn among customers with and without dependents.

### Service Analysis

- **PhoneService:** Compares churn among customers with and without phone service.

### Payments and Contract Analysis

- **Contract:** Examines churn across month-to-month, one-year, and two-year contracts.
- **PaperlessBilling:** Compares churn between customers using paperless billing and those who do not.
- **PaymentMethod:** Examines churn across the available payment methods.

Each analysis includes customer counts, churn-rate calculations, visualizations, and interpretations of the observed results.


## 7. Key Findings

The analysis is intended to identify patterns in customer churn across demographic groups, service arrangements, contract types, and payment methods.

The results should be interpreted using the churn rates and visualizations generated by the notebook. Differences in churn rates indicate associations in the observed data and do not, by themselves, establish causation.
